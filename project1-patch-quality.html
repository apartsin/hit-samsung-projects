Patch Quality Scanner

A deep learning model that scans a camera image in small patches and gives each patch an overall quality score plus a severity score for five distortion families: geometry, color, light, contrast and focus.

Credit
7 points
Team
Up to 3 students
Partners
HIT and Samsung
Area
Computer vision, image quality

A research project for an industry customer. There is no ready recipe: the team defines the details of the method, reads the literature, tries ideas, measures, and learns from what does not work. The project requires independent work, proactive exploration and a lot of trial and error, with regular meetings with the supervisor and periodic meetings with the Samsung team.

Description

Students build a model that takes an image, cuts it into overlapping patches (for example 128×128 pixels), and returns for every patch a vector of six numbers. The result is a set of quality maps over the image: where it is sharp or blurry, where the color is off, where it is over or under exposed, where contrast is flat, and where the geometry is bent.

Input: an RGB image (smartphone photo, any resolution).

Output per patch: [quality, geometry, color, light, contrast, focus], each in 0 to 1, where 0 means no distortion of that family.

Output per image: six heat maps and an overall score pooled from the patches.

The model is trained and tested on three sources of data:

  • Synthetic patches: clean, high quality images degraded with distortions of a known type and strength, so every patch gets an exact label for free.
  • Real public patches: public quality datasets with human opinion scores, including patch-level scores (PaQ-2-PiQ) and per-attribute ratings of smartphone photos (SPAQ, KonIQ++).
  • Proprietary Samsung dataset: real camera images provided by Samsung, used to adapt and validate the model on the target cameras and distortions.

Hard part: geometry is not visible inside a flat, textureless patch. No public dataset labels geometric distortion, so students generate it themselves and should study how much image context the model needs (patch size, neighbor patches, straight line cues) to detect it.

Motivation

Camera teams test new sensors, lenses and image processing pipelines on thousands of photos. A single quality number per image does not say what went wrong or where. A per patch, per distortion map points engineers directly at the problem: soft corners from the lens, a color cast in shadows, clipped highlights in one region. The same model can serve as an automatic judge in regression tests, a filter for training data, and a feedback signal for tuning the camera pipeline.

Recent research is moving in the same direction (models that locate a distortion, name its type and rate its severity), which makes this a current topic with room for a publishable result.

Goals and deliverables

  1. A distortion synthesis library in Python: one function per distortion, each with a strength parameter mapped to a 0 to 1 severity, able to mix several distortions and apply them locally (to a region) as well as globally.
  2. A training set generated from clean images, with per patch labels.
  3. A multi-head model that outputs the six scores per patch, and a script that produces heat maps for a full image.
  4. An evaluation report: accuracy on synthetic test data, correlation with human scores on public datasets, and results on the proprietary Samsung dataset.
  5. Optional: an on-device version (ONNX or TFLite) with measured run time on a phone.

Suggested approach

  • Backbone: start from a pretrained CNN or vision transformer (ConvNeXt, EfficientNet, ViT-S), or from an IQA pretrained encoder such as ARNIQA or CONTRIQUE.
  • Heads: one small regression head per family plus one for overall quality; try adding a distortion type classifier as an auxiliary task (as in LIQE).
  • Losses: regression (L1 or MSE) on severity, a ranking loss so that stronger distortion scores higher, and correlation based losses when fitting human scores.
  • Context: compare a pure patch model with a fully convolutional or transformer model that sees the whole image and outputs a dense map.
  • Calibration on human data: fine-tune the quality head on KADID-10k and PaQ-2-PiQ patch scores; check the light, color, contrast and focus heads against SPAQ and KonIQ attribute ratings.

What students will need

A map of the concepts, methods and tools this project touches. Students are not expected to know all of it at the start; the first weeks are for learning the essentials.

Concepts

  • Image formation and the camera pipeline (ISP)
  • Color spaces (sRGB, linear RGB, Lab), white balance, gamma
  • Lens distortion models (radial, tangential) and homographies
  • Blur and the point spread function, convolution
  • Full-reference vs. no-reference quality assessment
  • Mean opinion score (MOS), subjective testing

Algorithms and techniques

  • Synthetic data generation with known labels
  • Multi-task learning with several output heads
  • Regression, ranking and correlation losses
  • Self-supervised and contrastive pretraining
  • Transfer learning and fine-tuning
  • Sliding window inference, dense prediction, patch pooling
  • Data augmentation and domain shift handling

Models

  • CNNs: ResNet, EfficientNet, ConvNeXt
  • Vision transformers: ViT, Swin
  • IQA models: PaQ-2-PiQ, HyperIQA, MUSIQ, MANIQA, TOPIQ
  • Distortion-aware: ARNIQA, CONTRIQUE, LIQE
  • Vision-language IQA: CLIP-IQA, Q-Align (as baselines)

Evaluation

  • SRCC and PLCC (rank and linear correlation)
  • MAE of predicted severity
  • Type classification accuracy, confusion matrix
  • Cross-dataset generalization tests
  • Run time and model size on device

Tools and frameworks

  • Python, PyTorch, torchvision, timm
  • OpenCV, kornia, scikit-image, NumPy
  • Distortion code: ARNIQA, imagecorruptions, albumentations
  • pyiqa (IQA-PyTorch) for baseline metrics
  • Weights & Biases or TensorBoard for experiments
  • ONNX, TFLite for deployment; Git, GitHub

  3. Ying et al. From Patches to Pictures (PaQ-2-PiQ). CVPR 2020. Human patch scores and local quality maps.

  8. Chen et al. TOPIQ: A Top-down Approach from Semantics to Distortions.
  9. Zhang et al. LIQE: Blind IQA via Vision-Language Correspondence, a Multitask Approach. CVPR 2023. Joint quality, scene and distortion type.
